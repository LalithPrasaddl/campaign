# The Race

Five days until the vote. You're running for Congress against a man who has held the seat for eighteen years, and you're behind. You swore to three principles. Every town wants to hear something different.

A short text game about what winning costs. It takes about 10 minutes in the browser, with no sign-up.

## Play

Open `index.html`, or visit the GitHub Pages site once it's published.

## Develop

No build step. Edit the files and reload.

- `assets/js/content.js`: scenes, people and places
- `assets/js/engine.js`: game rules
- `assets/js/ui.js`: screens
- `node tools/sim.js 2000`: balance check

See `CLAUDE.md` for how it fits together and `docs/design-notes.md` for the design history.

This is an early build for feedback. The district, people and events are fictional.
